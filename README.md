# Movie Recommendation System 🎬

This is a machine learning-based movie recommendation system that suggests movies based on user preferences.

## Features
- Content-based filtering
- Suggests similar movies
- Simple and interactive output

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## How it works
The system analyzes movie metadata and recommends similar movies using similarity scores.
